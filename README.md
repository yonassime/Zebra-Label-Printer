# Zebra-Label-Printer
ILRI Zebra Label Printer — a lightweight web app that turns pasted CSV data into ready-to-print field and MTS distribution labels for genebank staff. Validates entries, generates ZPL matching the existing label format, and sends jobs directly to networked Zebra ZT410 printers (172.27.8.31:9100 and 172.27.8.45:9100).
